Lab 4.1: Internal Loopback Access

Exploit the stock checker to access http://localhost/admin via SSRF, read the admin HTML, and deliver the delete request for carlos.

⚠️
Objective: Intercept a stock check request, change stockApi to http://localhost/admin, then replay the discovered delete endpoint.

📡 Deployment Context Notice

You should not be able to browse directly to /admin from the browser. The intended path is to intercept a stock request, change the stockApi parameter to http://localhost/admin, inspect the HTML for /admin/delete?username=carlos, and then submit that full URL through the stock checker.
