================================================================================
                          KEY TESTING TIPS
================================================================================

1. PATH TRAVERSAL (Lab 1):
   - Try: ../ sequences, ..\ (Windows), ../../, absolute paths
   - Test different encoding: URL encoding, Unicode, case variations

2. ACCESS CONTROL (Lab 2):
   - Check robots.txt for hidden paths
   - Inspect HTML/JavaScript source for hidden endpoints
   - Modify cookies in browser developer tools
   - Try accessing admin endpoints directly
   - Enumerate user IDs/GUIDs

3. AUTHENTICATION (Lab 3):
   - Capture login requests in Burp Suite
   - Use Intruder for brute force with wordlists
   - Look for user enumeration differences in responses
   - Analyze session cookies and 2FA implementation

4. SSRF (Lab 4):
   - Try http://localhost/admin, http://127.0.0.1/admin
   - Exploit internal request functionality
   - Use Burp Collaborator or local tunneling

5. FILE UPLOAD (Lab 5):
   - Bypass file type checks with .php, .phtml, .php5 extensions
   - Modify Content-Type headers
   - Upload web shells and access them via /files/avatars/

6. COMMAND INJECTION (Lab 6):
   - Use command separators: ; && | || `
   - Test: whoami, id, cat /etc/passwd, ls, dir
   - Chain commands to verify execution

7. SQL INJECTION (Lab 7):
   - Single quote (') to break out of string context
   - Use -- or # for SQL comments
   - Try: OR 1=1, UNION SELECT, ORDER BY for column enumeration
   - Extract data using UNION attacks
